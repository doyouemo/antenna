# 2.4 GHz 圆极化贴片天线尺寸推导

> 目标：为 nRF52833 BLE AoA/AoD 测向板确定天线单元的尺寸。
> 参考设计：Nordic PCA20054 测向天线板。
> 日期：2026-09-10

## 1. 原理：为什么用传输线模型

微带贴片天线本质是一段**两端开路的微带传输线**：

```
         ← 贴片长度 L →
    ┌───────────────────────┐
    │                       │   ← 顶层铜（贴片）
    └───────────────────────┘
     ↑                       ↑
   边缘辐射缝隙          边缘辐射缝隙
    (fringing)             (fringing)
    
    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  ← 介质 1.6mm FR4
    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓
    ═════════════════════════  ← 底层地平面
```

- 贴片两端的开路边缘会**向外辐射**，这就是天线的工作方式
- 但边缘的电磁场不是突然消失，而是**向外"溢出"一小段距离**，叫**边缘效应（fringing）**
- 边缘效应让贴片**电学上比物理尺寸长一点**，每端多出 `ΔL`
- 所以谐振条件不是「物理长度 = 半波长」，而是「**物理长度 + 两端溢出 = 介质中的半波长**」

这就是推导的核心：

$$
\underbrace{L + 2\Delta L}_{\text{电长度}} = \frac{\lambda_0}{2\sqrt{\varepsilon_{reff}}}
$$

其中 `εreff` 是**有效介电常数**——因为贴片上半部分的场在空气里、下半部分在介质里，实际感受到的介电常数介于 1（空气）和 4.4（FR4）之间。

## 2. 公式

$$W = \frac{c}{2f}\sqrt{\frac{2}{\varepsilon_r+1}}$$

$$\varepsilon_{reff} = \frac{\varepsilon_r+1}{2} + \frac{\varepsilon_r-1}{2}\left(1+\frac{12h}{W}\right)^{-1/2}$$

$$\Delta L = 0.412h\cdot\frac{(\varepsilon_{reff}+0.3)(W/h+0.264)}{(\varepsilon_{reff}-0.258)(W/h+0.8)}$$

$$L = \frac{c}{2f\sqrt{\varepsilon_{reff}}} - 2\Delta L$$

**符号表：**

| 符号 | 含义 | 本次取值 |
|---|---|---|
| `c` | 光速 | 299.792458 mm·GHz |
| `f` | 工作频率 | 2.44 GHz |
| `εr` | 板材相对介电常数 | 4.4 (FR4) |
| `h` | 基板厚度 | 1.6 mm |
| `W` | 贴片宽度 | 待求 |
| `L` | 贴片长度（谐振方向） | 待求 |
| `εreff` | 有效介电常数 | 待求 |
| `ΔL` | 每端边缘溢出长度 | 待求 |

---

## 3. 逐步推导

### 基准量：自由空间波长

```
λ0 = c / f = 299.792458 / 2.44 = 122.866 mm
```

### ① 计算 W（宽度）

```
2/(εr+1)   = 2 / 5.4          = 0.370370
√0.370370                     = 0.608581
λ0/2       = 122.866 / 2      = 61.4329

W = 61.4329 × 0.608581        = 37.39 mm
```

### ② 计算 εreff（有效介电常数，用 W）

```
W/h       = 37.39 / 1.6       = 23.367
12h/W     = 12 / 23.367       = 0.513565
1.513565^(-1/2)               = 0.812829

εreff = 2.7 + 1.7 × 0.812829  = 4.0818
√εreff                        = 2.020347
```

> `(εr+1)/2 = 2.7`，`(εr-1)/2 = 1.7`

### ③ 计算 ΔL（边缘溢出）

```
分子 = (4.0818 + 0.3) × (23.367 + 0.264)
     = 4.3818 × 23.631                  = 103.551

分母 = (4.0818 - 0.258) × (23.367 + 0.8)
     = 3.8238 × 24.167                  = 92.418

比值 = 103.551 / 92.418                 = 1.120469

ΔL = 0.412 × 1.6 × 1.120469
   = 0.6592 × 1.120469                  = 0.7386 mm
```

### ④ 计算 L（谐振长度）

```
c/(2f√εreff) = 122.866 / (2 × 2.020347)
             = 122.866 / 4.040694       = 30.407 mm

2ΔL = 2 × 0.7386                        = 1.4772 mm

L = 30.407 - 1.4772                     = 28.93 mm
```

### 结果

```
W = 37.39 mm
L = 28.93 mm
```

---

## 4. 关键点：W 和 L 的地位完全不同

这一步是整个推导里最容易搞错的地方。

| | 性质 | 能不能改 |
|---|---|---|
| **L** | **被谐振频率锁死的硬约束**。它决定贴片在 2.44 GHz 谐振，动 0.1mm 就跑频 8MHz | ❌ 不能改 |
| **W** | **自由设计参数**。那条 W 公式的作用只是"给一个辐射效率、带宽、输入阻抗都还不错的默认值" | ✅ 可以改 |

**所以 W = 37.39 不是"天线必须是 37.39 宽"的意思**，它只是个推荐默认值。

> ⚠️ **曾经犯过的错误**：把 37.39 × 28.93 当成天线尺寸报出来。
> 公式和算术都对，但把「一个硬约束」和「一个软建议」并列当成同等的东西——**方法上是错的**。

## 5. 为什么参考板是 29 × 29 的正方形

因为**圆极化要求贴片是正方形**。

### 圆极化的原理

1. 正方形贴片有两个正交谐振模式：**TM10（横）** 和 **TM01（竖）**
2. 正方形时这两个模式**谐振在同一频率**（简并）
3. **对角切掉两个角** → 破坏对称性 → 两个模式被**劈裂成略有差别的频率 f1、f2**
4. 两个模式幅度相等、相位差 90° → 合成**圆极化波**

> **为什么必须切对角两个角，不能切四个角？**
> 切四个角的话结构仍然是四重对称的，两个模式照样简并在一起，等于白切。

### 所以

做圆极化时，**W 那条公式整个作废**，直接把 W 设成 L，得到正方形：

```
W = L = 28.93 mm  ≈  29 mm
```

**参考板的 29 × 29，就是计算出的 L 拿去做正方形。**

### 切角大小怎么定的

对角切角长度 `c` 决定模式劈裂量，需要的劈裂量由贴片 **Q 值**决定：

$$\frac{\Delta f}{f_0} = \frac{\Delta S}{S} \approx \frac{1}{Q}$$

两块对角三角形去掉的面积：

```
ΔS/S = c² / a² = 4.24² / 29²
     = 17.98 / 841        = 2.14%
```

反推 **Q ≈ 47**。

而 1.6mm FR4 上的 2.4GHz 贴片，Q 值本来就在 **30~60** 区间（薄基板 + FR4 损耗角 tanδ≈0.02）。
**算出来的需求和材料能给的正好对上**——这就是 4.24mm 的来源，不是随便取的。

### 切角缩小的后果

ΔS/S 与切角长度是**平方关系**：

| 切角 c | ΔS/S | 相对设计值 | 结果 |
|---|---|---|---|
| 1.5 mm | 0.27% | 1/8 | 基本退化成线极化 |
| 2.12 mm | 0.53% | 1/4 | 椭圆极化，轴比很差 |
| 3.0 mm | 1.07% | 1/2 | 勉强，轴比 4~6 dB |
| **4.24 mm** | **2.14%** | **1（设计值）** | ✅ 圆极化 |
| 6.0 mm | 4.28% | 2× | 劈裂过度，失配、增益下降 |

**结论：切角别动。**

## 6. 验证：29 × 29 到底谐振在哪

把 a = 29 代回公式：

```
a/h     = 29 / 1.6                = 18.125
12/a*h  = 12 / 18.125             = 0.662069
1.662069^(-1/2)                   = 0.775667

εreff   = 2.7 + 1.7 × 0.775667    = 4.018634
√εreff                            = 2.004653
```

```
ΔL = 0.6592 × (4.318634 × 18.389) / (3.760634 × 18.925)
   = 0.6592 × 79.4183 / 71.1650
   = 0.6592 × 1.115974            = 0.735650 mm

L_eff = 29 + 2 × 0.735650          = 30.4713 mm

f = 299.792458 / (2 × 30.4713 × 2.004653)
  = 299.792458 / 122.16620
  = 2.4540 GHz
```

**谐振在 2.454 GHz，比目标 2.44 GHz 高 0.57%。**

如果要**精确**落在 2.44 GHz，反解得边长 **a = 29.17 mm**。

参考板用 29.00 mm，两者差 0.17 mm —— **在模型精度范围内**。

---

## 7. 灵敏度：尺寸公差要求

从上面两个点算斜率：

```
Δf/Δa = (2.440 - 2.454) / (29.17 - 29.00)
      = -0.014 / 0.17
      = -83 MHz/mm
```

**每 0.1 mm 尺寸误差 = 8.3 MHz 频率偏移。**

蓝牙信道间隔 2 MHz，整个频段 83.5 MHz 宽（2.400 ~ 2.4835 GHz）。

| 尺寸误差 | 频率偏移 | 后果 |
|---|---|---|
| 0.05 mm | 4 MHz | 可忽略 |
| 0.1 mm | 8 MHz | 可接受 |
| 0.5 mm | 42 MHz | 半个频段 |
| 1.0 mm | 83 MHz | **整个频段** |

**所以：抄 29.00，不要自己改。** 这个尺寸对公差敏感，没有实测手段验证时不要动。

投板前跟嘉立创确认铜箔蚀刻公差。

## 8. 这个模型准不准：边界说清楚

**传输线模型是个近似，精度约 ±1~2%**，在 29mm 尺寸上就是 **±0.3 ~ 0.6 mm**。

它的假设与实际的偏差：

| 模型假设 | 实际板子 | 影响 |
|---|---|---|
| 地平面无限大 | 29mm 贴片，地是有限的 | 边缘绕射 → f 偏低 |
| 不受邻近影响 | 50mm 间距，天线间有互耦 | 阵列中互相牵引 |
| 没有切角 | 切了两个对角 | 去掉铜 → f 偏高 |
| 没有馈电结构 | 有馈线和匹配元件 | 引入电抗 → f 偏移 |
| 只算基模 | 存在高次模/表面波 | 效率、方向图偏差 |

> 注意：**切角去掉铜，本来就会让谐振频率往上跑。** 所以 29.00 实测很可能比 2.454 GHz 还要高一些。

**正确用法：这个公式算的是"起点"，要配合仿真或实测微调，不是算完就能直接投板。**

## 附：设计规则（布局时不能违反）

1. **12 个天线的切角方向和馈电点方向必须完全一致**，一个都不能旋转
   - 单看每个都是好圆极化，但有一个转了 90°，它收到的相位就跟别人差一截
   - AoA 算的就是通道间相位差 → **一致性坏了直接算错角度**
2. **所有馈线等长**
   - 参考板靠开关放在阵列中心、叶子开关四角对称（各距 57.21 mm）天然等长
   - 2×2 方案只要开关放正中间，4 条线靠对称性天然等长
3. **天线正下方不要铺内层铜**
   - 参考板内层只铺中央 100×100，天线下方全空
