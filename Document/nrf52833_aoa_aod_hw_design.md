## 1. 项目概述

本板为基于 Nordic **nRF52833** 的蓝牙方向定位（Direction Finding）评估/产品板：

- 支持 **BLE 5.1 AoA（来波角度）**：作为定位基站，用 **3×4 = 12 单元天线阵列**测来波方向；
- 支持 **AoD（出射角度）**：同一射频链路切到发射模式，作为标签让对端（手机等）测出射方向；
- 调试/日志采用 **CH340N**（USB 转串口，内置晶振）提供独立 UART 日志口 + **RTT**（SEGGER，走 SWD）实时调试；
- 不使用 nRF52833 内置 USB（USB 引脚空置，DECUSB 按规格书处理）。

## 4. 总体架构

- **射频路径**：ANT(H23) → 两级 RF 开关树 → 12 个贴片阵元。天线切换由 nRF 的 **PPI + GPIOTE + TIMER** 硬件时序驱动（与 CTE 时隙对齐），不占用 CPU。
- **数字路径**：nRF52833 的 UARTE 接 CH340N，CH340N 经 USB-C 输出虚拟串口；SWD 接 J-Link 用于烧录与 RTT。
- **角色切换**：同一硬件，固件按模式配置芯片为 CTE 接收（AoA locator）或 CTE 发射（AoD transmitter）。

## 6. 原理图设计要点

### 6.1 nRF52833 电源与去耦

- **VDD**：3.3V，就近放 100nF + 10µF 去耦。
- **DCC**（B3）：内部 DCDC 输出，接 **10µH 电感**到 VDD。若固定 USB 供电可只用外部 DCDC，内部 DCDC 用于电池低功耗模式。
- **DEC1/DEC3/DEC5**：稳压器去耦电容（100nF 级）。
- **DEC4(B5) 与 DEC6(E24)**：**必须用走线连在一起**，各放去耦电容。
- **VDDH(Y2)**：USB 未使用时可悬空（按规格书）。
- **DECUSB(AC5)**：USB 未使用，按规格书处理（悬空或按要求连接）。
- **VSS_PA(F23)**：射频地，就近打孔到主地。
- **底部焊盘**：必须接地。

> 具体电容数值**以规格书 “Supply pin decoupling” 表为准**，本表为典型参考值。

### 6.2 晶振

- **32MHz**：XC1/XC2 接 32MHz 晶振，负载电容按晶振 datasheet（典型 2×10~12pF）。
- **32.768kHz**：P0.00( XL1) / P0.01( XL2) 接 32.768kHz 晶振，负载电容典型 2×12pF。**必须接**（BLE 时序 + DF 功耗，见 §14）。
  - 占用 P0.00/P0.01，不能当 GPIO 用。

### 6.3 天线与 RF 开关树

两级 SP4T 树，实现 **1-of-12** 选择：

```
第一级:  3 × SP4T   → 每个开关接 4 个阵元（共 12）
第二级:  1 × SP4T   → 3 路第一级输出选 1（用 4 口中 3 口）
控制线:  3×2 + 2 = 8 根 GPIO
```

- 控制线接 nRF GPIO（见 §7），由 **PPI/GPIOTE 硬件**按 CTE 时序翻转。
- **ANT(H23) → 开关树**之间为 50Ω 走线。
- 开关供电电压要与控制电平匹配（典型 3.3V/1.8V，看型号）。

### 6.4 CH340N 串口电路

```
USB-C ──D+ ──22Ω/ESD── CH340N UD+
       └─D− ──22Ω/ESD── CH340N UD−
5V VBUS ──────────────→ DCDC → 3.3V → CH340N VCC
CH340N RXD ←── nRF TXD (P0.08)
CH340N TXD ──→ nRF RXD (P0.11)
CH340N RTS#/DTR# : 悬空（本板不需要自动复位/下载）
```

- CH340N **内置晶振**，无需外接晶振与负载电容。
- CH340N 3.3V 供电，I/O 电平 3.3V，与 nRF 直连。
- D+/D− 加 **22Ω 串联**和 **ESD 保护**。

### 6.5 SWD 调试接口（RTT）

- 引出 **SWDIO + SWDCLK + VDD + GND**（建议标准 4-pin 或 10-pin 排针）。
- 建议同时引出 **P0.18/nRESET**（复位与全功能调试）和 **P1.00/SWO**（可选）。
- RTT 复用 SWDIO/SWDCLK，烧录与 RTT 可同时使用。

### 6.6 复位、按键、LED

- **nRESET**：上电复位电路（RC 复位 + 调试器复位可选）。
- **按键**：P0.13，用于角色切换（AoA/AoD）或配置。
- **LED×2**：P0.05 / P0.06 状态指示。

## 8. 天线阵列设计

- **类型**：微带贴片天线（PCB 蚀刻），3 列 × 4 行。
- **中心距**：≈ 半波长 ≈ **61mm**（2.44GHz），两方向一致。
- **阵元尺寸**：约 30mm 见方（取决于板材 εr/厚度，**以仿真为准**）。
- **地平面**：贴片下层必须**完整地平面**，天线区禁止铺铜开槽/走线/器件。
- **馈电**：每阵元边缘馈电，50Ω 馈线引出；**12 根馈线等长、对称**，避免引入额外相位差。
- **隔离度**：阵元间尽量 >10dB，必要时用过孔墙/地槽。
- **阵列占板**：含地缘约 **170mm × 230mm** 以上，建议独立天线板与主控分板，或单大板。

## 9. 电源设计

- **输入**：USB 5V（来自调试口 VBUS）或外部 3.3V。
- **5V → 3.3V**：TPS62742 DCDC，输出 3.3V 供 nRF VDD、CH340N 及开关。
- **电池模式（可选）**：电池直供 VDD，启用 nRF **内部 DCDC**（DCC + 10µH）降低功耗；此时 3.3V LDO 供 CH340N 或断电。
- 各 DEC/VDD 去耦就近放置。

## 10. PCB 布局与叠层

**叠层（4 层）**：

| 层 | 用途 |
|---|---|
| L1 | 信号（贴片天线、走线） |
| L2 | 完整地平面 |
| L3 | 电源/地分割 |
| L4 | 信号/背面 |

- 天线区置于板边/独立板，**正反面净空**，地缘完整。
- ANT→开关→馈线全部 **50Ω 阻抗**（L1 到 L2 参考，注意线宽/间距）。
- 开关树靠近 ANT 与阵列馈电点，减少走线长度。
- 晶振、DCDC、RF 部分各自就近地，避免开关电源噪声串入射频。
- 8 根开关控制线从 nRF 到开关，尽量等长、短走线。

## 11. 调试与日志方案

| 手段 | 用途 | 说明 |
|---|---|---|
| **RTT** | 实时日志、时序敏感打印 | 走 SWD，需 J-Link；开发阶段主力 |
| **CH340N UART** | 独立串口日志 | 不依赖 nRF 固件/USB 驱动，崩溃时仍可出日志 |

日志输出建议：
- 开发期：RTT 打印 AoA 采样、角度、状态机；
- 联调期：CH340N UART（115200 或 1Mbps）输出结构化日志。

## 13. 风险与注意事项

1. **板载阵列相位一致性**是最大风险：依赖蚀刻公差、地平面、互耦。**必须做阵列相位校准**（nRF 有校准例程），量产建议按批校准。
2. **P0.09/P0.10 默认 NFC**：若不使用 NFC 且要当 GPIO，需在 UICR 配置 `NFCPINS` 禁用。
3. **32.768kHz 晶振不能省**：LFRC（内置 RC，±250ppm）会导致 BLE 时序超标、DF 监听功耗大幅上升。
4. **开关树 8 根控制线的时序**：由 PPI/GPIOTE/TIMER 硬件翻转，1µs 切换 + 1µs 采样的时序余量务必在固件侧验证。
5. **DECUSB**：USB 未用时的接法严格按规格书，避免漏接导致异常。
6. **贴片尺寸与间距需仿真**：文档中为典型参考，最终以 HFSS/CST 仿真与实物校准为准。
